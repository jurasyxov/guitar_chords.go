# 🎸 Guitar Chord Generator — аккорды для гитары в один клик

> «Не знаешь, как зажать аккорд? Мы покажем!»

**Guitar Chord Generator** — это набор консольных утилит для отображения аккордов на грифе гитары.  
Программа показывает схемы зажатия аккордов для различных тональностей и аппликатур, включая мажорные, минорные, септаккорды и многие другие.

## 🚀 Особенности
- 🎵 Поддержка всех основных аккордов: мажор, минор, септаккорд, мажорный септаккорд, минорный септаккорд, увеличенный, уменьшенный.
- 🎸 Отображение аппликатуры в виде ASCII-схемы грифа с 6 струнами.
- 🎚️ Настройка каподастра (транспонирование аккордов).
- 🔄 Смена позиции на грифе (открытая, баре, различные варианты).
- 📋 Список всех доступных аккордов с описанием.
- 🎨 Цветной вывод в терминале для лучшей читаемости.
- 💾 Экспорт схемы аккорда в текстовый файл (опционально).
- 🔊 Подсказки по аппликатуре (какие пальцы использовать).

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости (в основном стандартные библиотеки).

| Язык       | Зависимости              | Команда запуска                         |
|------------|--------------------------|-----------------------------------------|
| Python     | стандартная библиотека   | `python guitar_chords.py`               |
| Go         | стандартная библиотека   | `go run guitar_chords.go`               |
| Ruby       | стандартная библиотека   | `ruby guitar_chords.rb`                 |
| Java       | стандартная библиотека   | `javac guitar_chords.java && java guitar_chords` |
| JavaScript | Node.js, никаких         | `node guitar_chords.js`                 |
| C#         | .NET (или mono)          | `dotnet run`                            |
| Rust       | стандартная библиотека   | `cargo run`                             |
| PHP        | стандартная библиотека   | `php guitar_chords.php`                 |
